---

## 1. Executive summary

**Thesis:** Win the *execution loop*, not the task graph. Competitors sell lists, boards, calendars, or chat. Next sells relief: the system picks **Next**, prepares admin, the human acts/approves, and the plan updates on interrupt.

**Motion:** Product-led growth with a thin waitlist → invite → self-serve trial → paid. No SDR team. No custom demos forever.

**Sequence:** Message proof (prototype) → thin paid self-serve → scale the *one* channel that produced paying users.

**Do not:** Brand Next as “for CS,” sell Asana parity, run paid ads before “gets it” proof, or build GTM that needs Joseph on every activation.

---

## 2. Strategic thesis (Strategy)

| Win by | Lose by |
|--------|---------|
| Daily habit: open → do Next → done | Becoming another AI to-do with more views |
| Mental load + admin off the human | Competing on dashboard features |
| Role packs as *onboarding templates* only | Locking brand to one vertical |
| Self-serve activation in minutes | Founder-led onboarding as the product |

**Long-term market:** Anyone who works with priorities, interrupts, and admin drag.  
**Beachhead (first buyers, not brand):** High-interrupt individual knowledge workers — ICs, leads, managers, operators, founders — drowning in calendar + Slack/email decision fatigue. They already try Notion/Todoist/etc. and still feel load.

**Positioning map**

| Alternative | They optimize | Next |
|-------------|---------------|------|
| Todoist / lists | Capturing tasks | One Next to execute |
| Asana / ClickUp | Team dashboards | Individual execution first |
| Motion | Calendar packing | Work-unit execute + approve |
| ChatGPT | Ad-hoc answers | Sequences work; you complete |

**Line:** *Stop managing work. Just do Next.*

## 3. Messaging (Marketing)

- **Brand line:** Next. Do the work. Leave the load.
- **Value sentence:** Next is a work execution system that decides what you should do next—and carries the admin and mental load so you only complete work.
- **Proof points:**
  1. One Next, not a board.
  2. System prepares; you approve irreversible acts.
  3. Interrupts replan the route—plans aren’t sacred.

**Copy starters**
- Hook: You’re not behind. You’re managing work instead of doing it.
- CTA: Spend eight minutes in the prototype. If it feels like relief, join the waitlist.
- Anti-category: Lists organize work. Next gets it done.

## 4. Product readiness for GTM (Product)

**Must be true before paid GTM**

A stranger can: (1) name their work context in plain language, (2) get a credible first Next without a dashboard, (3) complete ≥1 real work unit with system-prepared admin, (4) survive one interrupt → replan.

| In v1 (paid gate) | Out of v1 |
|-------------------|-----------|
| One Next surface | Multiplayer / SSO as launch requirement |
| Session brief from calendar + pasted notes | Deep auto-send across Slack/email |
| AI prepare + human approve | Full stakeholder graph |
| Interrupt → replan | Dashboards / list-grooming features |
| Light work memory | Vertical kits as *required* path |

**Aha (activation):** Completes a real work unit they did *not* prioritize themselves, after approving system prep — and accepts one replan. Proxy: open → first Done ≤10 min.

**v1 eats:** prioritization, context-gathering, draft prep, “what’s next,” reschedule suggestion after interrupt.  
**Later:** auto-commit/send, calendar rewrite, cross-tool triage, team routing.

**Low-touch learning:** Instrument TTF-Done, % time doing vs organizing, approve/edit rates, D1/D7 execution opens. Cap: ~5 async interviews per 25 activated users/month. No concierge onboarding.

## 5. Go-to-market motion (Sales)

**Type:** Waitlist → invite → 14-day self-serve trial (PLG). Light product-led sales only for high-intent expansion later — not outbound hunting.

**Conversion path**

```
Prototype / content → Waitlist → Invite + trial
  → First Done <5–10 min → Daily execution habit
  → Paywall → Pro → (later) Team
```

**Pricing hypothesis (experiments, not final)**  
- Free waitlist / trial  
- **Pro $19–29/mo** (test $19 vs $29)  
- Annual ~10× monthly  
- Team seats later ($15–20/seat) — not the GTM wedge  

**Top objections**

1. “Another AI to-do” → Show one Next, not boards.  
2. “Won’t trust AI” → Human approve for irreversible acts.  
3. “I have Notion/Todoist” → Those organize; Next executes.  
4. “Too early” → Waitlist + clear v1 scope.  
5. “Need team/SSO” → Individual first; team is expansion.

**Founder “sales” time:** ~3–5 hrs/week — invite triage, a few learning chats (not demo theater), pricing/churn review. Cap live calls.

## 6. Channels & launch (Marketing)

**Primary (90 days):** Founder-led LinkedIn — 2 posts/week + 1 short demo clip/week. Calm professional audience; matches tone; no ad spend required.

**Secondary:** Warm 1:1 invites to people who already feel priority thrash (signal > scale).

**Defer:** Product Hunt, paid ads, SEO content mill — until waitlist quality and “gets it” rates are proven.

**Launch assets**
- [ ] One-page landing (brand line, value, 3 proofs, CTA)
- [ ] Waitlist (email + role + “what drains you most?”)
- [ ] Prototype link + 60–90s Loom of the loop
- [ ] LinkedIn pin + 5 post outlines
- [ ] Design-partner invite template (async-first)
- [ ] FAQ: what Next is / isn’t (3 bullets)

**90-day marketing targets (directional)**  
≥150 waitlist · ≥40% prototype loop completion among starters · ≥15 design chats · unaided “not another to-do” recall in chats

## 7. Phased plan & kill criteria (Strategy)

| Phase | Focus | Kill / pause if |
|-------|--------|-----------------|
| **0–30 days** | Public prototype + outcome landing; ~30 structured feedback loops; waitlist only; track “gets it &lt;2 min” | &lt;40% grasp “not a to-do” without coaching |
| **30–90 days** | Self-serve alpha (paste OK); price test; D7 return for *execution* | D7 execution &lt;15% **or** waitlist→paid &lt;10% (once paywall live) |
| **90–180 days** | Scale the single channel that produced paid users; optional role packs as onboarding skins | Still needs Joseph on every activation |

## 8. Finance guardrails (Finance)

*Estimates for planning — not forecasts.*

**Pricing tests:** Bands ~$12–19 / $29–39 / $49–79 monthly; don’t lock until ~30–50 paying users.

**CAC:** Organic-first. Soft rule: blended CAC ≤ ~1× first-month ARPU; paid only with path to payback ≤90 days cash.

**Red flags:** Cash payback &gt;3 months · refunds &gt;8–10% of new subs · monthly churn &gt;~8% · support time per user climbing → pause paid spend.

**90-day spend envelope**

| Mode | Rough total |
|------|-------------|
| $0 | ~$0–50 (existing tooling) |
| Lean | ~$150–400 (domain, analytics, email) |
| Modest | ~$500–1,200 (lean + ≤$200–500 ad tests) |

**Spend ads only after** organic converts, guardrails hold, and one channel repeats. Until then: stay organic.

## 9. Explicitly out of GTM

- Enterprise outbound / SDR motion  
- Team seats, SSO, or admin consoles as launch requirements  
- Feature parity with Asana/ClickUp  
- Paid acquisition before message + activation proof  
- Vertical brand lock-in (“Next for CS”)  
- Content/SEO mill as primary motion  
- Concierge setup as the path to value
